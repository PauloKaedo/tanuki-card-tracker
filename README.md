
# 🎴 Tanuki Card Tracker

**A Python-based camera tracking tool for Trading Card management.**

Tanuki Card Tracker is a simple yet powerful tool designed to streamline the process of cataloging Trading cards. Leveraging OpenCV, the tool uses your webcam to capture cards in real time and allows for their easy registration into a CSV file.

---

## 🚀 Features
- **Live Camera Feed**: Seamlessly displays real-time video from your webcam.
- **Card Registration**: Detects and tracks cards for quick cataloging.
- **CSV Export**: Automatically saves card details to a CSV file.
- **User-Friendly**: Easy-to-use interface with minimal setup.

---

## 🛠️ Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/tanuki-card-tracker.git
   cd tanuki-card-tracker
   ```
2. Install the dependencies:
   ```bash
   pip install -r requirements.txt
   ```

---

## 📄 Usage

1. Run the script:
   ```bash
   python main.py
   ```
2. Follow the on-screen instructions:
   - Press 's': Capture and register a card.
   - Press 'q': Exit the live feed and save the catalog.

---

## 🧰 Requirements

- Python 3.7+
- OpenCV 4.10.0+
- NumPy 1.21.2+
